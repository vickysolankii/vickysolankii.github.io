<h1>About me</h1>

I'm **Vicky Solanki**, a technical support engineer. I work on user and system issues across Windows and Linux, and I write down every fix so it can be repeated.

## What I work with
- **Operating systems:** Windows 10/11, Windows Server, Ubuntu and other Linux distributions
- **Networking:** TCP/IP, DNS, DHCP, VPN, Wi-Fi, basic firewall rules
- **Support work:** ticket handling, remote support, root cause analysis, documentation
- **Tools:** Event Viewer, PowerShell, Command Prompt, Bash, Wireshark, VirtualBox

## How I troubleshoot
1. Understand the problem and who it affects
2. Reproduce it and check logs
3. Fix it with the smallest safe change
4. Verify, then document it
